# PC Check

PC・周辺機器の動作確認をブラウザ上で行うWebサイトです。
ソフトウェアをインストールせず、キーボード、マウス、モニター、マイク、スピーカー、Webカメラ、ゲームパッドなどの基本動作を確認できるサイトを目指しています。

This is a web-based tool for checking the basic functionality of PCs and peripheral devices.
The goal is to provide simple browser-based checks for keyboards, mice, monitors, microphones, speakers, webcams, gamepads, and other devices without requiring software installation.

## 主な機能 / Features

* 日本語キーボード（JIS 109キー）チェック
  Japanese keyboard (JIS 109-key) check

* キーボードのチャタリング確認
  Keyboard chatter detection

* マウス動作チェック
  Mouse input check

* マウスのチャタリング確認
  Mouse chatter detection

* モニター表示チェック
  Monitor display check

* マイク入力チェック
  Microphone input check

* スピーカー出力チェック
  Speaker output check

* Webカメラチェック
  Webcam check

* ゲームパッドチェック
  Gamepad check

* 画面・ブラウザ基本情報表示
  Basic screen and browser information

## 対応環境 / Recommended Environment

Google Chrome / Chromium系ブラウザを推奨します。

Google Chrome or other Chromium-based browsers are recommended.

一部の高度なチェック機能は、ブラウザの対応状況やユーザーによる権限許可が必要です。

Some advanced diagnostic features may require browser support and explicit user permission.

## 注意事項 / Disclaimer

このサイトはブラウザ上で取得できる情報を利用した簡易動作チェックツールです。
ハードウェアの故障や正常性を完全に保証するものではありません。

This site provides basic functionality checks using information available through the web browser.
It does not provide a complete hardware diagnosis or guarantee that a device is free from faults.
